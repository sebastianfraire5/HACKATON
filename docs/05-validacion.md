## 1. El Test de los 5 Segundos
Ponemos el celular o la laptop frente a la persona durante **5 segundos exactos**, cerramos la pantalla y preguntamos:

> **"¿Para qué sirve esto y a quién ayuda?"**

* Si responde algo como: *"Es para ver si la comida de las escuelas llega bien o si se roban la plata de las viandas"* 👉 **El mensaje funciona.**
* Si responde: *"Es un dashboard de datos de CABA"* o *"No entendí si es para comprar criptomonedas"* 👉 **Hay que simplificar la pantalla principal de inmediato.**
